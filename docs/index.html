Frame a frame.

AnimPro é um editor de animação 2D para Android, criado para desenhar, experimentar poses, organizar frames e exportar animações sem exigir uma conta para começar.

Uma oficina de animação no teu telefone

✏️ Desenha

Usa ferramentas de desenho, formas, vários estilos de pincel e grelha de referência.

🎞️ Organiza frames

Cria, duplica e remove frames. Ajusta a reprodução e usa onion skin para comparar poses.

🧩 Experimenta poses

Usa os controlos simples de pose e guarda os resultados como frames.

📦 Exporta

Exporta imagens, sequências PNG, GIF e MP4, conforme a compatibilidade do dispositivo.

📱 Projetos locais

Começa sem conta. Os projetos ficam no dispositivo e podem ser transferidos com backups .animpro.

🔐 Conta opcional

O projeto inclui autenticação Firebase quando configurada. A autenticação não significa sincronização automática dos projetos.

Feito para criar, não para complicar

O AnimPro foi pensado para um fluxo de trabalho direto: abre um projeto, desenha, anima e exporta. Guarda cópias dos teus projetos importantes e verifica a compatibilidade do teu dispositivo antes de instalar uma versão.
